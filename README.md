# Luker WebDAV 备份 0.3.0

同一个仓库安装两次：服务端插件管理中安装后端并重启；扩展管理中安装前端并重新加载页面。

仓库：https://github.com/Aouky7/luker-webdav-backup

## 本版改进

- 优先读取 WebDAV PROPFIND 的 getcontentlength 属性，不再把只有 HEAD 返回的 0 直接判成空备份。
- 区分大小一致、大小不一致、大小未知、仅查询到大小但没有本地对照记录。
- 云端备份列表显示名称、时间与大小，并支持对已有文件重新查询大小，无须重新上传。
- 最近一次成功上传任务有本地发送记录时，重新复核会更新任务状态。历史文件没有本地记录时，只显示查询结果，不声称验证一致。
- 前端主动加载带版本号的同目录样式，减少旧清单、缓存或样式加载失败导致的无样式布局。

## 更新文件

后端目录需要 index.mjs 和新增 webdav.mjs 两个文件。前端目录需要 frontend.js、style.css、manifest.json 三个文件。两端均更新到 0.3.0 后重启后端并重新加载页面。

不要只替换 index.mjs：缺少 webdav.mjs 会导致后端启动失败。通过软件中的 Git 扩展更新可自动取到全部文件，前提是对应版本已经提交到仓库。

本地更新包本身不代表 GitHub 已更新，发布状态以交付消息为准。

## 复核现有备份

保存原有 WebDAV 配置，在云端列表刷新后找到同名 ZIP，点击大小复核。如果它也是最近一次上传任务，会对照本地发送字节数。图示备份本地发送量为 166112986 字节，坚果云界面四舍五入显示 158.4 MB；界面显示值不足以证明逐字节相同。

大小一致只证明大小一致，不是内容哈希校验、ZIP CRC 检查或恢复验证。本版不下载整个 ZIP，不执行恢复，也不删除远端文件。

## 范围与兼容性

- HTTPS、用户名/应用密码认证；服务须支持 PROPFIND、PUT、MOVE，并接受未知长度流式上传。
- 目标目录必须已存在。坚果云需使用 /dav/ 下的专用文件夹。
- 列表仅接受配置目录内、符合本插件命名规则的最终 ZIP；不含 .partial、子目录、外站地址或其他软件备份。
- 单次目录响应最多 2 MiB；超限明确报错，不静默截断。前端列表最多返回 200 项，超过会提示。
- 部分服务可能自行限制 PROPFIND 返回数量，列表只能显示服务返回的条目。
- ZIP 未加密，数据库导出可能包含未勾选分类与机密。请使用私有目录。

## 验证

运行 `node --test tests/*.test.mjs`。包含 DAV XML 与大小校验回归测试，以及模拟 HTTPS/宿主的路由集成测试，覆盖 HEAD 假零、真实空文件、属性失败、错误/截断 XML、目录隔离、管理员访问、复核状态持久化和响应上限。

未连接用户坚果云账户进行实测；也未对实际 ZIP 做完整性或恢复验收。前端真实设备主题效果需更新后确认。
